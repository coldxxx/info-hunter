## 实际模块与剩余耦合

| 范围 | 当前边界 | 仍需注意 |
| --- | --- | --- |
| 主后端 | radar 保留公共函数/CLI、安全 HTTP 与调度；连接、存储、领域路由、编排分别提取 | 各领域通过当前 services/函数协作，补丁点、schema 顺序、锁与事务需要持续保持 |
| schema/迁移 | database.initialize 组织各领域 schema、种子加载、快照与索引 | 仍有写副作用，status 不是纯只读；尚未新增独立只读诊断入口 |
| SQL/查询 | source/article API 负责领域查询，主题、质量、分组由共用模块提供 | 计数、列表、详情、分页仍需联合验证，DTO 不等于运行时响应校验 |
| content/任务 | content_store 与 native jobs 分别持有主库和任务库，通过认证 RPC 同步 | GET 内容刷新会写状态/正文并使语义失效；迟到结果和重启需要跨进程实测 |
| 来源说明 | source_details 描述共用策略与实际能力 | 文字仍需随实现/预算更新，不能据描述宣称账号接通 |
| 模型/worker | semantic_worker、translation_model 拆分任务执行和模型调用，领域模块保留兼容函数 | 模型、阈值、指纹、预算和复核资格仍相互关联，真实效果另行评估 |
| native | state 显式准备，bridge 限定缓存，media 处理流式边界，service 负责认证/lifespan | service 导入会初始化；LaunchAgent 标签固定，安装会切换 checkout |
| 前端 | lib/api/DTO 共用，features 按 workspace、feed、articles、topics、sources、platform、media、semantic 分层 | URL、轮询、草稿和回调有既有契约；完整 API schema 与多环境交互矩阵尚未建立 |
| 两种构建 | Vinext 与 React/Vite 复用页面 | 每次相关改动分别构建；生成产物与运行实例不混用 |

公开来源、模型本地端点、native RPC 和公众号 loopback 是不同信任边界，不合成无限制 HTTP 工具。`refresh-platform` 仍只返回成功，实际刷新由客户端重读；这是保留的业务行为。部分领域类型/显示工具仍可在实际扩展时按需求统一，不以继续重构代替验收。

## 验证与限制

已记录核心 185 项、native 11 项与前端 API 6 项通过。native 使用迁移的实际 Python 3.12.12 和既有依赖，ASGITransport 不启动 lifespan worker；认证/Origin、token 权限/复用、健康/连接、上传清理/大小、DNS拒绝、桥接缓存/重定向均隔离检查。提取函数体及 token/WAL 初始化通过 AST 对比，独立模块导入不初始化私有目录。

最终构建和隔离 UI 数量、完整命令与环境由变更记录给出，不能提前声称运行实例或真实平台完成验收。内置 Browser 的 Node runtime 无法启动，原因未确定；替代浏览器检查的环境和范围应单独记录。

1. 构建/回归不证明运行实例使用新源码；现有实例、LaunchAgent 与数据库未切换。
2. 模拟 API/DOM 与模型联调不证明账号权限、后续增量或长期稳定；历史结果只适用于原环境。
3. 公众号后续文章/定时/失效恢复、具体会员站点、真实字幕/音轨分支需要实际样本。
4. 语义合成样本不提供自动资格，需代表性人工标签与当前防护后的量化评估。
5. 快照集合因 Reddit 规则变化，必须核对 saved_annotations 与非 Reddit 内容，不能仅比较总数或复制活跃库。
6. 状态 CLI/部分 GET 存在副作用，正式核验用明确只读副本或约定实例接口；隔离路径不等于授权/网络完全隔离。

验证记录包含日期、revision、命令、形态、结果与限制，私有原始资料留被忽略目录。未来步骤不写成完成。
